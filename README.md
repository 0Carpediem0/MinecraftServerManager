# Minecraft Server Manager

Первая рабочая версия локального настольного менеджера Minecraft Java Edition для Ubuntu Desktop. Интерфейс полностью на русском. Приложение создаёт изолированные профили, ставит сервер из официальных источников, запускает и корректно останавливает его, показывает живой журнал, управляет `server.properties`, памятью, резервными копиями и серверными модами из Modrinth.

## Возможности

- Vanilla — официальный серверный JAR и контрольная сумма Mojang.
- Fabric — стабильный loader и официальный server launcher Fabric.
- Forge — официальные стабильные/recommended установщики для Minecraft 1.17–1.21.x.
- NeoForge — официальные стабильные установщики начиная с Minecraft 1.20.2.
- Версии Minecraft загружаются из манифеста Mojang и показываются по дате, от новых к старым. Снапшоты выключены по умолчанию.
- Каждый сервер хранится в отдельном профиле. Версия и загрузчик после установки не меняются: для другой комбинации создаётся новый профиль.
- Кнопки Run и Stop, состояние процесса и живой журнал. Stop отправляет штатную серверную команду `stop` и ждёт сохранения мира.
- EULA никогда не принимается автоматически: пользователь открывает официальный текст и сам ставит отметку.
- Перед установкой, изменением настроек, установкой/удалением модов создаётся ZIP-копия всего профиля.
- Поиск Modrinth фильтруется по версии Minecraft, загрузчику и поддержке серверной стороны. Приложение добавляет обязательные зависимости, проверяет заявленные несовместимости и контрольные суммы SHA-512.
- Новые профили создаются с `online-mode=false`: сервер не обращается к проверке лицензии Minecraft. Публичный туннель playit включён по умолчанию и запускается вместе с сервером.

Каталог совместимости не может гарантировать отсутствие конфликтов между модами. Моды, добавленные вручную, приложению неизвестны. Некоторые серверные моды также нужны на клиентских ПК — это указано авторами конкретных модов.

## Полная установка на Ubuntu Desktop

Откройте терминал и последовательно выполните весь блок. Скрипт сам установит Python, Tkinter, Java 21 и агент playit:

```bash
sudo apt update
sudo apt install -y git

git clone https://github.com/0Carpediem0/MinecraftServerManager.git
cd MinecraftServerManager
chmod +x install-ubuntu.sh run.sh
./install-ubuntu.sh
```

После завершения **выйдите из учётной записи Ubuntu и войдите снова**. Это нужно, чтобы ваш пользователь получил доступ к системной службе playit. Затем запустите приложение:

```bash
cd ~/MinecraftServerManager
./run.sh
```

Установщик добавляет Python 3, Tkinter и OpenJDK 21 из репозиториев Ubuntu. Minecraft 1.20.5–1.21.x обычно использует Java 21; точное требование читается из официального манифеста выбранной версии. Minecraft 26.x требует Java 25. Если такой версии нет в репозитории вашей Ubuntu, установите JRE/JDK 25 из доверенного пакета дистрибутива или Eclipse Temurin и выберите `/.../bin/java` на вкладке «Настройки». Приложение проверит точную основную версию перед установкой и запуском.

Сторонние Python-пакеты не требуются.

Установка playit в скрипте использует его [официальный APT-репозиторий](https://playit.gg/download/linux). При первом Run агент напечатает в живом журнале ссылку привязки. Откройте её, создайте туннель типа Minecraft Java на локальный адрес `127.0.0.1:25565`, затем передайте игрокам выданный playit внешний адрес. Проброс порта и публичный IP при этом не нужны. Туннель можно отключить на вкладке «Настройки» и настроить порт роутера самостоятельно.

### Ошибка `/run/playit/playitd.sock`

Если приложение пишет, что сокет доступен только группе `playit`, выполните:

```bash
sudo usermod -aG playit "$USER"
```

После этого полностью выйдите из учётной записи Ubuntu и войдите снова. Простого закрытия терминала недостаточно. Проверить применение можно командой `id -nG`: в списке должна появиться группа `playit`.

## Первый запуск сервера

1. Нажмите «Обновить версии», выберите версию и тип сервера, создайте профиль.
2. На вкладке «Настройки» укажите Java и RAM, затем сохраните.
3. Нажмите «Установить». Forge и NeoForge могут скачивать библиотеки несколько минут.
4. Откройте Minecraft EULA по ссылке, прочитайте её и сами поставьте отметку принятия.
5. Нажмите Run. Когда журнал покажет `Done`, сервер готов.
6. На этом ПК подключайтесь к `localhost`. Из интернета используйте внешний адрес, показанный агентом playit в журнале.

Приложение не меняет роутер и брандмауэр. Внешний доступ обеспечивает отдельно установленный агент playit; без него сервер остаётся доступен только там, куда позволяет ваша сеть.

`online-mode=false` позволяет игрокам без проверки учётной записи выбрать произвольное имя, включая имя администратора. Не выдавайте `op` по имени на таком публичном сервере без отдельного серверного мода аутентификации. Публичный сервер также стоит защитить резервными копиями и ограничениями прав модов.

## Данные и восстановление

По умолчанию данные находятся в:

```text
~/.local/share/minecraft-server-manager/
├── profiles/<id>/
└── backups/<id>/*.zip
```

Для восстановления остановите сервер, закройте приложение, сделайте отдельную копию текущей папки профиля и распакуйте содержимое выбранного ZIP в папку соответствующего профиля. Не смешивайте миры разных версий Minecraft.

Можно задать отдельную папку данных:

```bash
./run.sh --data-dir /путь/к/данным
```

## Проверка разработчиком

Из корня проекта:

```bash
python3 -m unittest discover -s tests -v
python3 tests/gui_smoke.py
```

Автоматические тесты используют фиктивные JAR и тестовый процесс, поэтому не принимают EULA и не создают настоящий Minecraft-сервер.

## Источники метаданных

- Mojang version manifest и серверные загрузки: `piston-meta.mojang.com`, `piston-data.mojang.com`
- Fabric metadata и launcher: `meta.fabricmc.net`
- Forge promotions и Maven: `files.minecraftforge.net`, `maven.minecraftforge.net`
- NeoForge Maven: `maven.neoforged.net`
- Modrinth API: `api.modrinth.com/v2`

Для работы приложения нужен HTTPS-доступ к этим адресам и к адресам файлов, возвращаемым Modrinth.
